# Markdown Viewer - Native Android/Kotlin

Native Android/Kotlin Markdown Viewer with:

- SAF file open for `.md`, `.markdown`, `.txt`
- `Open with` support via Android intent filters
- Markdown rendering with tables
- Tags from YAML frontmatter and inline hashtags
- Font family and font size controls
- Android text-to-speech

## Build

```bash
./gradlew assembleDebug
```

APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```
